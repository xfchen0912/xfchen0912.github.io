# Xufeng Chen pixel academic website

A static, single-page academic website based on the content of the November 2026 CV. This independent variant combines modern academic typography with original pixel-style scientific illustrations; the previous design remains in the sibling `academic_website` directory.

The public-facing version is intentionally selective: three research themes, three representative publications, concise education and selected honours. Its visual system uses orange, ink, plum, green and teal to connect the pixel artwork with the research narrative.

## Preview locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## Deploy with GitHub Pages

1. Create a public repository named `USERNAME.github.io`.
2. Copy the contents of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then `main` and `/ (root)`.
